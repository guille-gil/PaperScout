# The user's manuscript: working rules

Read once per task, when `map action=show` lists a manuscript. The .tex and .bib are read-only: never edit them unless asked. Everything below is `map action=manuscript op=...`, and every list is capped. `scope` returns the draft's brief (title, abstract, sections, what it already cites, the user's in and out of scope): read it at the start of any literature workflow and keep every query inside it. Whether a sentence needs a source, and whether a cited paper supports its sentence, are your judgement, made on request in batches: `review` returns up to 30 uncited sentences (`about=` a section) and `support` up to 8 cited ones with what is known of each paper; judge as their instructions say and record with `judge`. A batch costs about 1 to 2k tokens and verdicts are remembered, so stop when the user has what they asked for. `gaps` lists what is flagged. To find papers, search for one place at a time: `search for=<place id>` (add `query=` with your own wording if the automatic one is off) returns a ranked shortlist of at most 5, marked when the draft already cites them; the user chooses on the Desk. `comments` lists open supervisor comments with the sentence each is about. When the user pastes comments, split them into blocks separated by a blank line (a line starting with `> ` quotes the passage, `by: NAME` names the author) and record them with `intake text=`; a Word or PDF file goes in with `intake path=`.
