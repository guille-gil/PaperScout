# Session log

Write `notes/<YYYY-MM-DD>-<slug>.md` covering: what was done in this session, the strongest findings or decisions, open questions and unresolved risks, concrete next steps, and the artifacts written (paths under `outputs/`, `papers/`, `notes/`, `experiments/`). Include direct source URLs for any external claim that matters. If `CHANGELOG.md` exists, append a two to four line entry pointing to the log. Reply with the path only, plus the `Next:` line if work remains.
