# Feynman for Cowork

The research workflows of [Feynman](https://github.com/companion-inc/feynman), adapted as skills and subagents for Claude's Cowork mode.

Start with `/feynman:start` (it shows the menu of workflows), run any workflow directly, and stop with `/feynman:end`. The skills never trigger on their own, so ordinary tasks stay ordinary.

Paper access comes from the Paper Scout extension in this repository (`../extension`), which runs on your computer and reads your Zotero library directly.
